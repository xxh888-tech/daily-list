# 每日清单

一个本地可编辑、支持局域网访问的每日任务清单。

## 启动

在当前目录运行：

```bash
python server.py
```

浏览器打开 `http://localhost:8000`。同一 Wi-Fi 下的其他设备打开终端输出的局域网地址即可访问和编辑，所有设备共享 `data.json` 数据。

也可以指定端口：`python server.py 8080`。

首次运行会自动生成 `data.json`。如 Windows 防火墙弹窗，请允许 Python 访问专用网络。

AI 复盘配置：编辑根目录的 `config.json`，填写 `deepseek_api_key`（不要把真实 Key 提交到代码仓库），然后重启服务。默认使用 DeepSeek `deepseek-chat` 模型。

## 功能

- 按日期浏览、添加、编辑、删除和完成任务
- 可为任务设置具体时间，列表会按时间自动排序
- 标记特殊日子，记录早餐、午餐、晚餐和每日体重
- 每日复盘：记录当日心情、今日亮点、困难、感恩、明日计划和一句话总结
- AI 生成复盘：前端将当日全部复盘内容 POST 到 `/api/ai/review`，由 DeepSeek 生成结构化建议
- 消费和收入均支持添加多笔记录，并自动统计当日、当月和当年总额
- 工作、生活、学习、健康、其他分类及优先级
- 关键词搜索、待完成/已完成筛选、完成进度
- 学习数据统计：今日完成率、本周任务趋势、各分类累计时间、连续学习天数，并汇总本周复盘和心情
- 一级分类支持子分类统计，可进入分类详情查看各项目的任务次数、完成数量和累计时长
- 学习分类支持教资科目一、教资科目二、教资科目三、英语单词、英语听力、编程学习、AI学习等二级分类；学习详情展示总时长、最近学习日期及本周/本月/年度时长
- 工作分类支持项目开发、日常工作、其他等项目类型；工作详情展示项目投入排行榜、周期投入时间、趋势和项目成果记录
- 目标管理支持健康、学习、工作、生活的周/月/年目标，自动关联任务及健康、学习、工作统计计算完成度；另支持独立减肥目标，读取每日体重计算目标体重完成度
- AI个人成长报告整理本周健康、学习、工作数据，调用 DeepSeek 生成结构化周成长分析
- 任务支持可选量化字段：`type`、`category`、`duration`、`distance`、`count`、`subject`、`project`、`work_type`、`achievement`；同时保留兼容旧数据的 `metrics` 字段
- 健康分类提供跑步、篮球、跳绳等运动数据中心，支持 `sport_type`、距离、时长、次数及周/月/年度趋势，并可点击运动类型进入详情
- `/api/stats` 返回按一级分类、类型/科目/项目聚合的任务次数、完成数、时长、距离及数量统计，并提供周/月/年度趋势
- 数据持久化到本地 `data.json`，统计直接读取现有任务和每日记录；旧任务缺少子分类或量化字段时自动兼容为“未分类”并使用估算逻辑
- 响应式移动端界面与深色外观
